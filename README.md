# Antigravity Multi-Account Cockpit

[中文版](./README.md) | [English Version](./README_EN.md)

> Antigravity 多账号切换与配额管理助手

一个强大且优雅的 VS Code 插件，专门用于管理多个 Antigravity 账号及其模型配额。

## 🌟 核心功能

- **多账号仪表盘 (Dashboard)**：采用直观的 Tab 页设计，一目了然地查看各账号下的 Gemini、Claude 等模型配额。
- **双周期配额同屏监控**：同屏呈现 5 小时滑动窗口与 7 天周配额，告别单维度切换，无 5H 额度的 Free 账号智能精简呈现。
- **配额持久化与重启即显**：内存 + 磁盘快照双层缓存设计，IDE 重启后首屏立即可见所有账号配额，彻底告别“配额数据待刷新”白板与频繁请求。
- **一键切换账号**：全自动流程。点击切换后，插件自动处理进程关闭、数据库与系统凭据注入并重新启动。深度适配 Antigravity 2.6+ 新版凭据机制与旧版多版本架构。
- **官方原生分组与状态栏联动**：直接对接 Google 官方原生 `quota_groups`，状态栏采用紧凑双周期语法并由三色状态灯（🟢/🟡/🔴）动态联动告警。
- **智能 OAuth 认证**：内置 Google 授权流程，支持自动跳转或手动复制授权链接，解决各种浏览器环境下的兼容性问题。
- **Token 登录与导出**：支持通过 Refresh Token 直接登录，支持单个账号导出或批量导出/导入所有账号（JSON 格式），完美解决多设备间的账号同步、备份与迁移问题。
- **跨平台支持**：完整支持 **Windows / macOS / Linux** 三大平台，自动适配路径与进程管理逻辑。
- **多语言支持**：界面、命令、提示信息及状态栏均已完成深度国际化，支持 中文(简/繁)、英文、日文、韩文、俄文、法文、西班牙文、德文、意大利文 等 10 种语言。

## ✨ 主要功能

### 🗂️ 模型分组管理与动态提取

- **官方原生分组对接**：全面废弃手工单模型 ID 映射，直接同步 Google PA 官方 `quota_groups` 原生分组结构。
- **分组参考账号选择**：支持自动汇聚所有已登录账号的有效分组，或指定单个账号作为参考基准，解决不同订阅权限账号间的模型差异。
- **幽灵分组智能清理**：仅提取当前账号真实拥有的有效配额，一键重新提取并自动清理失效或未拥有的幽灵分组（如 Free 账号不再残留 Argon 高级模型占位）。
- **自定义简称与排序**：支持为各分组配置自定义短简称（如 `Claude`、`Gemini`）及上下移动排序，命名防冲突引擎智能区分同名家族系列。
- **全量国际化弹窗**：分组管理设置弹窗支持 10 语种无缝切换，界面清新紧凑。

### 📊 状态栏增强与双周期联动

- **紧凑型双周期展示**：状态栏严格遵循紧凑排版规范，如：

  ```text
  🟢 Claude: 80%/90% | 🟡 Gemini: 44%
  ```

  - 斜杠 `/` 区分 **5 小时滑动配额** 与 **7 天周配额**；
  - 竖线 `|` 区分各启用模型分组；
  - 纯文本呈现，避免非必要 Emoji 占宽。
- **三色小球动态告警**：各分组前置三色指示灯（🟢/🟡/🔴），依据 `min(5H, 周额度)` 的实际最吃紧配额动态变色，与面板阈值严格统一：
  - 🟢 充足：余量 > 50%
  - 🟡 紧张：余量 21% ~ 50%
  - 🔴 告急：余量 ≤ 20%
- **极简 Markdown 悬停面板**：鼠标悬停状态栏时弹出紧凑 Tooltip：
  - 采用 🕒 (5H) 与 📅 (周) 紧凑图标直观标记配额条与重置倒计时；
  - 去除繁琐中文字符，保障在各 IDE 语言环境下具备极高可读性；
  - 完美修复 Markdown 语法加粗与等宽对齐渲染。

### ⚡ 双配额周期同屏呈现与 UI 精炼

- **同屏一体化展示**：移除顶部单维度配额切换按钮，卡片与列表视图均实现双周期同屏并列呈现。
- **卡片视图 (Card View)**：
  - 具备 5H 额度的账号同屏上下展示 ⚡ 5H 滑动桶与 📅 7 天周配额双进度条；
  - 无 5H 额度的 Free 账号自动隐藏灰色空条及提示噪音，界面极致清爽。
- **列表视图 (List View)**：
  - 分组配额列采用 🕒 / 📅 天然跨语言图标标记；
  - 模型列表按字母 A-Z 稳定升序排序，消除服务端返回乱序带来的查找困扰；
  - 针对过期配额优雅显示 ⌛ 沙漏图标。
- **原生 CSS 平滑进度条**：
  - 彻底抛弃 Unicode 字符拼接（`█░`）方案，采用内联 `.tt-bar` / `.tt-fill` 样式；
  - 彻底消除 Windows 字体字形度量不一引起的进度条高度错位问题；
  - 进度显示精度升级为 0%~100% 连续平滑渲染。

### 💾 配额数据持久化（重启即显）

- **双层缓存架构**：在内存缓存基础上引入 `cached_quota` 本地磁盘快照存储。
- **秒开体验**：VS Code 或 IDE 重启后，仪表盘 Phase 1 首屏直接读取本地快照快速回填，告别大面积“待刷新”白板与网络重连等待。
- **超期智能标识**：自动检测各账号配额是否超过重置时间，超期时显示 ⚡ 标识并悬浮提示用户手动刷新。

### ⏱️ 定时自动刷新

- **可配置刷新间隔**：1-60 分钟可选，默认 5 分钟。
- **管理界面设置**：在仪表盘右上角直接调整刷新频率。
- **VS Code 设置**：也可通过 `antigravity-cockpit.autoRefreshInterval` 配置。
- **实时生效**：修改配置后立即生效，无需重启。

### 🔌 连接状态监测

- **自动检测**：按配置的刷新间隔自动检测账户连接状态。
- **失败提示**：连接失败时状态栏显示 `$(error) 连接失败`。
- **智能通知**：首次失败弹出警告通知，避免频繁打扰。
- **一键重连**：
  - 点击状态栏尝试重新连接；
  - 通知弹窗提供【重新连接】【关闭】按钮。
- **成功反馈**：重连成功后显示“连接成功！”提示。

### 🔑 Token 登录与导出 (跨设备同步)

- **Token 登录**：粘贴账号的 Refresh Token 即可直接登录，无需通过浏览器打开 OAuth 页面。
- **单个导出**：在账号卡片的操作按钮组中，点击 🔑 按钮即可快速复制该账号的 Refresh Token。
- **批量导出 (JSON)**：点击顶部 📦 按钮，可将所有已登录账号的 Token 导出为 JSON 格式并复制。
- **批量导入**：点击顶部 📥 按钮并粘贴已导出的 JSON，可一次性同步所有账号。
- **响应式布局**：仪表盘头部按钮组支持自动换行，适配各种宽度的侧边栏环境。

### 🔄 跨平台账号切换与 Antigravity 2.6+ 深度适配

- **双模式切换**：
  - **安全模式 (safe)**：仅切换插件内当前账号，提示用户手动重启 IDE（适合谨慎用户）；
  - **高级模式 (advanced)**：完整自动流程 - Kill 进程 → 注入 Token / 凭据 → 自动重启 IDE（默认）。
- **Antigravity 2.6+ 凭据同步**：
  - 自动识别并适配 Antigravity 2.6+ 全新凭据存储机制，同步写入 Windows 原生凭据管理器（`gemini:antigravity`）；
  - 自动探测多版本数据库路径，兼容 2.6+ 共享存储与 <= 2.5.5 旧版独立目录结构。
- **跨平台路径适配**：
  - Windows: `%APPDATA%\Antigravity\User\globalStorage\state.vscdb`
  - macOS: `~/Library/Application Support/Antigravity/User/globalStorage/state.vscdb`
  - Linux: `~/.config/Antigravity/User/globalStorage/state.vscdb`
- **协议优先启动**：优先尝试 `antigravity://` 协议，失败时自动回退到可执行文件路径。
- **安全备份**：注入前自动备份 `state.vscdb`，生成 `.ag-backup-<timestamp>` 文件。
- **可配置覆盖**：支持自定义数据库路径和可执行文件路径。

### 🔧 诊断与调试工具

- **环境自检命令** (`antigravity-cockpit.diagnoseEnvironment`)：
  - 检查 Node.js 可执行路径；
  - 验证数据库路径存在性与读写权限；
  - 检测 Antigravity 可执行路径；
  - 生成可复制的诊断报告。
- **日志快速访问** (`antigravity-cockpit.openSwitchLogs`)：
  - 一键打开账号切换日志目录 (`%TEMP%/ag_switch_*.log`)；
  - 方便排查切换失败问题。

## ⚙️ 配置选项

| 配置项 | 说明 | 默认值 |
| -------- | ------ | -------- |
| `antigravity-cockpit.autoRefreshInterval` | 自动刷新间隔（分钟），1-60 可选 | `5` |
| `antigravity-cockpit.switchMode` | 账号切换模式：`safe` (手动重启) / `advanced` (自动完整流程) | `advanced` |
| `antigravity-cockpit.databasePathOverride` | 数据库路径覆盖（留空使用平台默认路径） | `""` |
| `antigravity-cockpit.antigravityExecutablePath.win32` | Windows 平台 Antigravity.exe 路径覆盖 | `""` |
| `antigravity-cockpit.antigravityExecutablePath.darwin` | macOS 平台 Antigravity.app 路径覆盖 | `""` |
| `antigravity-cockpit.antigravityExecutablePath.linux` | Linux 平台 Antigravity 可执行文件路径覆盖 | `""` |
| `antigravity-cockpit.language` | 界面语言：`auto` (自动) / `zh-cn` (中文) / `en` (英文) 等 | `auto` |
| `antigravity-cockpit.processWaitSeconds` | 进程状态检查等待时间（秒），5-60 可选 | `10` |

## 🛠️ 安装与开发

### 依赖环境

- **Node.js**: >= 16.x
- **Antigravity**: ^1.80.0

### 快速开始

1. 克隆本项目到本地。
2. 在项目根目录运行安装依赖：

   ```bash
   npm install
   ```

3. 编译插件代码：

   ```bash
   npm run compile
   ```

4. 在 VS Code 中按 `F5` 启动 **扩展开发宿主** 窗口即可开始使用。

## 📖 使用指南

### 打开管理面板

点击界面右下角状态栏的账号图标（如 `$(account) user`），或者按下 `Ctrl+Shift+P` 搜索并运行命令：`Antigravity: 打开账号管理面板`。

### 添加新账号

在管理面板右上角点击 **"+ 添加新账号"**，在弹出的对话框中选择“自动打开浏览器”或“复制链接”，完成授权后插件会自动同步新账号。亦可直接使用 **Token 登录** 粘贴已有的 Refresh Token。

### 切换账号

在管理面板中选择对应的账号 Tab，点击右上方的 **"切换到此账号"** 按钮即可。注意：在高级模式下，此操作会自动关闭并重启 Antigravity 以确保配置生效。

### 模型分组与状态栏设置

1. 点击管理面板右上角的 **"⚙️ 分组管理"** 按钮；
2. 在弹窗顶部选择【分组参考账号】（可选择“自动汇聚全部账号”或指定高权限账号）；
3. 点击 **"重新提取"** 自动拉取官方最新模型分组并清理幽灵分组；
4. 按需勾选需要在状态栏展示的分组、自定义简称并使用 **"↑ / ↓"** 调整排序；
5. 点击 **"保存"**，状态栏即刻生效最新的紧凑双周期指示。

### 设置刷新频率

- **方式一**：在管理面板右上角的下拉菜单中选择刷新间隔；
- **方式二**：打开 VS Code 设置，搜索 `antigravity-cockpit`，修改 `Auto Refresh Interval`。

## 📁 项目结构

- `src/extension.ts`: 插件入口及命令注册中心。
- `src/dashboardProvider.ts`: 基于 Webview 的交互式仪表盘实现（含卡片/列表视图与双周期同屏呈现）。
- `src/accountManager.ts`: 账号数据的持久化、双层缓存（内存+磁盘快照）及配额 API 交互。
- `src/modelGroupManager.ts`: 官方原生模型分组管理器，负责分组提取、幽灵分组清理与别名排序。
- `src/dbManager.ts`: 负责对 `state.vscdb` 的安全注入、凭据适配与数据编码。
- `src/processManager.ts`: Antigravity 进程的生命周期管理（查找/关闭/重启）。
